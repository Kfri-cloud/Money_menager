# 01. 과제 요구사항

## 결과물과 환경

파일 입출력 기반 콘솔 가계부 애플리케이션 1개를 만듭니다. Python 3.10 이상에서 동작하고, 별도 `pip install` 없이 표준 라이브러리만 사용해야 합니다. 원문의 학습 시간은 60시간입니다.


| 기능                       | 입력                                                    | 필수 결과                                        |
| -------------------------- | ------------------------------------------------------- | ------------------------------------------------ |
| `add`                      | 날짜·종류·카테고리·금액·메모·태그를 대화형 입력    | 저장, 생성된 고유 ID 출력                        |
| `list`                     | `--limit N`                                             | 최신순, 건수 제한, 제너레이터 처리               |
| `search`                   | `--from`, `--to`, `--category`, `--type`, `-q`, `--tag` | 조건에 맞는 거래를 최신순 출력, 스트리밍 유지    |
| `summary`                  | `--month YYYY-MM`, `--top N`                            | 총수입·총지출·잔액·카테고리별 지출 TOP N      |
| `budget set`               | `--month`, `--amount`                                   | 월 예산 영구 저장, summary에서 사용률·초과 경고 |
| `category add/list/remove` | 추가·삭제할 이름                                       | 분류 관리, 사용 중인 분류 안전 처리              |
| `update`                   | `--id`와 수정 필드 또는 대화형 입력                     | 수정, 없는 ID 안내, 재실행 후 유지               |
| `delete`                   | `--id`                                                  | 삭제, 없는 ID 안내, 재실행 후 유지               |
| `import`                   | `--from CSV경로`                                        | 일괄 등록, 처리 건수 출력                        |
| `export`                   | `--out CSV경로`와 월 또는 기간                          | CSV 생성, 처리 건수 출력                         |

`import/export`가 두 명령이므로 명령은 총 10개입니다. 원문 최종 결과물의 10번째 항목은 별도의 저장 파일·README 조건입니다.

## 영구 저장과 최초 실행

- JSONL 또는 CSV 중 하나를 내부 저장 형식으로 선택합니다.
- 거래·카테고리·예산을 최소 3개 파일로 나눕니다.
- 기본 경로 `./data`를 권장하며, 옵션으로 변경할 수 있어야 합니다.
- 파일이 없으면 자동 생성하거나 초기화 안내를 출력합니다.
- 카테고리가 비었으면 기본값을 만들거나, 등록을 안내하고 거래 추가를 막습니다.
- 수정·삭제는 안전하게 전체를 재작성합니다. 임시 파일 작성 후 원본 교체를 권장합니다.

실습의 JSONL 스키마:

```text
data/transactions.jsonl  # {id, type, date, amount, category, memo, tags}
data/categories.jsonl    # {name}
data/budgets.jsonl       # {month, amount}
```

JSONL은 한 줄에 JSON 객체 하나입니다. 한 월에 하나의 예산을 유지하고 같은 월을 다시 설정하면 갱신합니다.

## CLI와 오류

모든 명령에 `--help`를 제공합니다. 옵션 표기는 `--limit`, `--month`처럼 `--`를 사용합니다. 원문에 별도로 명시한 메모 검색 `-q`도 제공합니다.

`add`는 대화형 입력이 필수입니다. `search/list/summary/export/import/delete`는 옵션 입력이 허용됩니다. `update`는 옵션형 또는 대화형 중 선택하고 README에 명시합니다.

오류는 스택트레이스 대신 **원인 + 해결 힌트**로 출력합니다. 정상 종료는 0, 오류 종료는 0이 아닌 값입니다. 예외 처리·로그·시간 측정 중 하나 이상의 공통 관심사를 데코레이터로 직접 구현해 실제 적용해야 합니다.

## 세부 완료 조건

- 목록과 검색은 최신 날짜순입니다. 입력 순서와 날짜순은 다를 수 있습니다.
- 검색은 기간·분류·종류·메모·태그를 지원합니다. 실습에서는 여러 조건을 AND로 결합합니다.
- 월별 잔액은 해당 월 수입에서 해당 월 지출을 뺀 값입니다.
- 해당 월 거래가 없으면 `데이터 없음`을 출력합니다.
- 예산이 있으면 지출/예산 × 100과 초과 여부를 표시합니다.
- 사용 중인 카테고리는 삭제를 막거나 다른 분류로 이관합니다. 실습에서는 삭제를 막습니다.
- `export`에는 `--month` 또는 `--from`과 `--to` 조건을 받습니다. 무조건 전체 내보내기만 구현하면 부족합니다.

## CSV 계약

UTF-8 인코딩과 헤더를 사용합니다. 내부 ID는 CSV 필수 열이 아니며 가져올 때 새로 생성합니다.


| 열         | 필수   | 값                      |
| ---------- | ------ | ----------------------- |
| `date`     | 예     | `YYYY-MM-DD`            |
| `type`     | 예     | `income` 또는 `expense` |
| `category` | 예     | 등록된 카테고리         |
| `amount`   | 예     | 양수 정수               |
| `memo`     | 아니요 | 문자열                  |
| `tags`     | 아니요 | 쉼표 구분 문자열        |

CSV 인용 처리는 `csv` 모듈에 맡깁니다. 행을 직접 `split(',')`로 나누면 쉼표가 포함된 메모·태그를 잘못 읽게 됩니다.

## 선택 보너스

타임스탬프 백업, 반복 거래, 표 출력 개선, 저장 원자성 강화는 선택입니다. 원문은 수정·삭제의 안전한 재작성을 필수로 설명하고 임시 파일·원자적 교체를 권장하며, 저장 원자성 강화를 보너스에도 제시합니다. 실습에서는 임시 파일 교체를 기본 설계에 포함합니다.
