# 용돈 기입장 5일 학습 진행 지표

이 표는 **아이의 학습 진행**과 **과제 PDF의 제출 요구**를 확인하는 자료다. 하루가 끝날 때 실제 실행 결과를 보고 표시한다. 학습 점수가 높아도 PDF 필수 항목이 빠지면 과제 완료로 표시하지 않는다.

## 기록 방법

각 항목에 `0`, `1`, `2` 중 하나를 적는다.

- **0:** 아직 시도하지 않았거나 실행되지 않는다.
- **1:** 설명을 보고 한 번 동작했지만 다른 입력 또는 재실행에서는 확인하지 못했다.
- **2:** 스스로 실행했고 표의 확인 기준을 두 번 이상의 입력으로 확인했다. 결과를 말로 설명할 수 있다.

하루 4항목, 최고 8점이다. 5일 합계는 **40점**이다. 점수는 성적이 아니라 다음 날 무엇부터 도울지 판단하는 표시다. `2`를 적을 때는 파일 이름이나 화면에 나온 숫자 등 짧은 근거를 남긴다.

| --- | --- | --- | --- | --- |
| 1 | 입력과 출력 | 다른 날짜·분류·금액을 두 번 입력하고 그대로 출력 |  |  |

## PDF 필수 요구사항 제출 점검

아래 칸은 **실제 제출 프로그램**을 실행한 뒤에만 표시한다. 1~2일차 연습 파일이 작동한 것만으로는 완료가 아니다.

| 요구 | 확인할 증거 | 완료 |
| --- | --- | --- |
| 거래 추가 `add` | 날짜·종류·분류·금액·메모·태그 입력 후 생성 ID 출력 | [ ] |
| 목록 `list` | 최신순, `--limit` 적용, 파일 한 줄씩 읽기 | [ ] |
| 검색 `search` | `--from`, `--to`, `--category`, `--type`, `-q`, `--tag` | [ ] |
| 월별 요약 `summary` | 수입·지출·잔액·카테고리 지출 TOP N, 데이터 없는 달 안내 | [ ] |
| 예산 `budget` | 월별 설정 저장, 요약에서 사용률과 초과 경고 | [ ] |
| 카테고리 `category` | add/list/remove와 사용 중 분류 안전 처리 | [ ] |
| 거래 수정 `update` | ID로 수정, 없는 ID 안내, 재실행 후에도 유지 | [ ] |
| 거래 삭제 `delete` | ID로 삭제, 없는 ID 안내, 재실행 후에도 유지 | [ ] |
| CSV 가져오기 `import` | 정해진 헤더·UTF-8, 처리 건수 출력 | [ ] |
| CSV 내보내기 `export` | 월 또는 기간 조건, 헤더·UTF-8, 처리 건수 출력 | [ ] |
| 저장과 실행 | 거래·카테고리·예산 파일 3개, `python -m budget_app` | [ ] |
| 코드 구조 | 클래스 2개 이상, 모듈 3개 이상, 타입 힌트 | [ ] |
| 심화 문법 | 파일 스트리밍 제너레이터와 실제 적용한 데코레이터 | [ ] |
| 오류 처리 | 원인·해결 힌트, 추적 화면 없음, 0이 아닌 종료 코드 | [ ] |
| 사용 설명 | README의 실행법·저장 위치·명령 예·CSV 형식이 실제와 일치 | [ ] |
