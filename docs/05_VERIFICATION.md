# 구현 및 검증 결과

검증일: 2026-10-15 (한국 시간). Windows, Python 3.14.7에서 표준 라이브러리 `unittest`로 실행했습니다. 코드의 최소 지원 버전은 Python 3.10이며, 3.10 인터프리터에서의 별도 실행 검증은 하지 않았습니다.

```text
python -m unittest discover -s tests -v
Ran 12 tests
OK
```

## 자동 검증 범위

1. 샘플 4건의 월 합계, 조건 결합 검색, 기간 양 끝 포함, 최신순 정렬, 예산 초과 출력.
2. 실제 별도 CLI 프로세스의 대화형 추가 → 옵션 수정 → 삭제와 재실행 후 저장 확인.
3. CSV 월별 내보내기 → 새 폴더 가져오기 왕복과 쉼표 포함 메모·복수 태그 보존.
4. CSV 두 번째 데이터 행 오류에서 이전 거래 파일의 바이트가 유지되는지 확인.
5. 없는 ID·잘못된 날짜·미등록 분류·수정 옵션 없음·손상 행에서 원본 보존.
6. 카테고리 추가·삭제·사용 중 삭제 거부, 예산 재설정과 파일 재로딩.
7. 중복 ID 및 저장 금액의 잘못된 타입 거부.
8. 잘못된 옵션·월·limit·top·기간·ID에서 오류 종료, 해결 힌트, 스택트레이스 없음. 최상위 및 모든 명령·하위 명령 도움말 확인.
9. 원본 JSONL 경로 내보내기 거부, 실패 시 기존 출력 CSV 보존.
10. os.replace 권한 실패를 모의하여 원본 바이트와 임시 파일 정리 확인.
11. 1만 건의 순서가 섞인 날짜에서 최신순·동일 날짜 순서·월 합계와 제너레이터 조기 종료 확인.
12. 헤더만 있는 CSV, 필수 헤더 누락, 실제 CLI 카테고리 추가·목록·삭제 확인.

첫 테스트 시도는 Windows 샌드박스의 임시 디렉터리 접근 제한으로 시작하지 못했습니다. 동일 테스트를 해당 제한 밖에서 실행해 위 결과를 확인했습니다.

## 범위와 한계

- 1만 건 테스트는 기능 검증이며 메모리 사용량을 직접 측정한 벤치마크는 아닙니다. 전체 거래를 Python 리스트에 올리지 않는 구조를 코드로 확인했습니다.
- 실패한 파일 교체는 모의 권한 오류로 검증했습니다. 실제 디스크 고장·정전 복구는 검증하지 않았습니다.
- 단일 프로세스를 전제로 하며 동시 쓰기 잠금과 다중 파일 트랜잭션을 지원하지 않습니다.
- 선택 보너스 중 임시 파일 교체를 구현했습니다. 별도 백업 명령·반복 거래는 포함하지 않았습니다.
- 수동 점검표는 추가 검토용 양식으로 남겼으며 자동 검증 결과는 이 문서에 기록했습니다.
